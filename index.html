Research

RoarNet: A Robust 3D Object Detection based on RegiOn Approximation Refinement

Kiwoo Shin*, Youngwook Paul Kwon*, Masayoshi Tomizuka · IEEE Intelligent Vehicles Symposium 2019 · 290+ citations · 2nd place, KITTI 3D detection benchmark (Jul 2018)

RoarNet detects cars in 3D from a camera image plus a LiDAR scan — without requiring the two sensors to be tightly time-synchronized. The key idea is to let the image do the first pass: a 2D network estimates each object's full 3D pose directly from the monocular image using geometric agreement search (a 3D box must project back onto its own 2D detection), then scatters a handful of candidate positions along the camera ray. That collapses an enormous 3D search space into a few short line segments. A PointNet-based second stage then reads the raw points inside each candidate region and recursively refines the box's location, rotation, and size. Because the point clouds are never cropped by the 2D box, detection degrades gracefully when camera and LiDAR fall out of sync — where prior state-of-the-art methods drop sharply.

epBRM: Improving the Quality of 3D Object Detection using an End Point Box Regression Module

Kiwoo Shin, Masayoshi Tomizuka · IEEE Intelligent Vehicles Symposium 2020

LiDAR detectors have a common failure mode: many predictions land right next to a real object, but the box fits too loosely to count as a detection. Rather than building yet another detector, epBRM is a tiny plug-in module that refines any detector's output: it samples the raw points around each predicted location and regresses a precise 3D box, using a spatial-transformation (centering) mechanism to make the regression easy enough for a very small PointNet. Bolted onto AVOD, F-PointNet, or PointPillars, it improves 3D detection on KITTI after just 40 minutes of training, adding less than 12 ms of inference overhead for up to 20 objects.

small_world_model — World Models from Scratch on One GPU

A from-scratch implementation of LeWM, a decoder-free JEPA-style world model, trained on MuJoCo robot tasks on a single DGX Spark and evaluated by goal-image planning: encode a goal image once, CEM-plan through latent rollouts, execute — no decoder anywhere. The repo is built as a rigorous study: chance/collapse baselines are permanent guards, and a committed chain of evidence localized why the paper's GoalMSE cost fails at this scale (SIGReg whitens the latent space so latent distance decorrelates from task distance — even though a linear probe reads the true state to 1.5 cm) before a DINO-WM baseline head-to-head. Active — the task ladder is climbing toward contact-rich manipulation.

Camera-Only Imitation Learning for Robotic Cable Insertion

A learned visuomotor policy that inserts SFP fiber-optic plugs into NIC ports with a UR5e — from RGB cameras only, no ground-truth poses, no depth. Built on the Intrinsic AI for Industry Challenge toolkit, with oracle distillation, ACT-style policy learning, a hardened evaluation harness, and a statistics-first experiment log. A curriculum-insertion phase then produced the project's first fully learned seats (best 93/100), off-center recovery at 2–3 mm offsets, robustness across randomized scenes, and a separate model for the harder angled SC fiber connector — with failures scored and shown alongside the successes.
